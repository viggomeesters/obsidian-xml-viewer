# Changelog

## 0.1.1 - 2026-10-25

- Cross-platform production build.
- Current Community installation documentation.


All notable changes to XML Viewer are documented here.

## 0.1.0 - 2026-06-07

- Initial public release.
- Add read-only `.xml` file view.
- Add tree view with element, attribute, namespace prefix, text, comment, CDATA, processing instruction, and document type rendering.
- Add source view with line numbers and lightweight XML syntax highlighting.
- Add search/filter over XML node names, attributes, values, text, comments, and CDATA.
- Add malformed XML parse warnings with source-view fallback.
- Add top-level outline and 10,000 node render cap for large XML files.
